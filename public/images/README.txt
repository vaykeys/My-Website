# IMAGES FOLDER (Public Assets)

Store your personal photos and project screenshots here!
Any image saved in this folder will be automatically included in your Vercel deployment.

Suggested filenames:
- profile.jpg    (Your profile picture for the Home page)
- project1.jpg   (Screenshot for Project 1)
- project2.jpg   (Screenshot for Project 2)
- project3.jpg   (Screenshot for Project 3)

How to use:
In your HTML files, point to:
<img src="images/profile.jpg" alt="[Your Name]">
