# IMAGES FOLDER

Store your personal photos and project screenshots in this folder!

Suggested filenames:
- profile.jpg    (Your profile picture for the Home page)
- project1.jpg   (Screenshot for Project 1)
- project2.jpg   (Screenshot for Project 2)
- project3.jpg   (Screenshot for Project 3)

How to use your images:
1. Save your image file into this `images/` folder.
2. In your HTML files (such as `index.html` or `projects.html`), update the image src attribute:
   <img src="images/profile.jpg" alt="Photo of [Your Name]">
3. The existing CSS will automatically fit and style your image!
